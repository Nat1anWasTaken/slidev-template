# Google Sans font source

The Google Sans variable WOFF2 file in this directory was downloaded from the
official Google Fonts service on 2026-08-04. It is the Latin subset returned
by the CSS API for the regular, medium, semibold, and bold weights.

- Specimen: <https://fonts.google.com/specimen/Google+Sans>
- CSS API: <https://fonts.googleapis.com/css2?family=Google+Sans:wght@400;500;600;700>
- Google Fonts terms: <https://developers.google.com/fonts/terms>

The file is unmodified. Review Google's current font and trademark terms
before redistributing this theme outside this local presentation project.

# Noto Sans TC / Noto Serif TC subsets

`NotoSansTC-subset.woff2` (variable, wght 400–700) and `NotoSerifTC-subset.woff2`
(static 500) are generated by `scripts/subset-fonts.py` from the variable TTFs in
google/fonts (pinned commits, see the script), subset to the characters listed in
`cjk-glyphs.txt`. Licensed under the SIL Open Font License 1.1 (`OFL-NotoTC.txt`).
Rebuild with `pnpm fonts` after changing on-slide text; `pnpm fonts:check` reports
missing characters.
